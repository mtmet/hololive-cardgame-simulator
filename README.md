# hololive-cardgame

hololive OFFICIAL CARD GAME (hOCG) の非公式シミュレーターです。React + TypeScript + Vite 製で、自分のPCで起動して利用します。

## 特徴

- 総合ルールに基づくルールエンジンとカード効果の自動処理
- CPU対戦（Master / Expert / Hard / Normal / Easy）と、自動保存・途中再開
- デッキの作成・編集、ブラウザーへの保存、JSONの書き出し・読み込み
- ローカルのリレーサーバーを使った2人対戦・観戦
- カードのドラッグ＆ドロップ・タップ操作、スマホ表示への対応
- ゲーム開始・ターン進行・アーツ・効果発動・サイコロ・勝敗の演出

## セットアップ

Node.js 20以上とPython 3.10以上を用意してください。

### 1. 依存関係のインストール

```bash
npm ci
python -m pip install -r tools/extraction/requirements.txt
```

### 2. カードデータの取得

カードデータ・画像はリポジトリに含まれません。公式サイトから取得してください。

```bash
python tools/extraction/card_extract.py
```

取得結果は次の場所に保存されます。

```text
data/
  holomen.json            ホロメンカード
  oshi_holomen.json       推しホロメン
  support.json            サポートカード
  yell.json               エールカード
  sample_decks.json       公式おすすめデッキ
  card_images/           カード画像
  card_backside_images/  カード裏面画像
```

5つのJSONはアプリの起動に必要です。カード番号ごとの通常版から本文を取得し、ホロメン・推し・サポートの別イラストと各画像のレアリティも保持します。エールは同じ番号の定型文なし再録版を除いて通常版1画像を採用します。

裏面画像は公式オフィシャルルールブックPDFから取得し、角の外側が透明なPNGとして保存します。おすすめデッキも公式サイトのレシピを使用します。

全件の取得・検証が成功した後、`data/` 全体を置き換えます。旧画像や独自ファイルも削除されるため、独自ファイルは別の場所へ保存してください。通信や解析に失敗した場合は元の `data/` を保持します。

### 3. ローカルで起動

```bash
npm run dev
```

[http://localhost:5173](http://localhost:5173) をブラウザーで開きます。ホーム画面からデッキの作成・編集、CPU対戦、部屋コードを使った対戦を選べます。

ビルドしたアプリをローカルで利用する場合:

```bash
npm run build
npm run serve
```

[http://localhost:8787](http://localhost:8787) を開きます。`npm run serve` はビルド済みアプリの配信と対戦リレーをまとめて起動します。停止は `Ctrl+C` です。

`npm run preview` でもビルド結果を確認できますが、対戦リレーは起動しません。2人対戦には `npm run dev` または `npm run serve` を使用してください。

## CPU対戦

自分とCPUのデッキ、CPUの強さ、先攻・後攻を選んで開始します。デッキの「ランダム」はサンプル・保存済みデッキから抽選します。

- **Master** — 候補を比較・選抜し、有望な行動へ探索を集中するCPU
- **Expert** — 相手の非公開情報を補いながら、行動列と相手の返しを探索するCPU
- **Hard** — 候補を適用した盤面を評価して行動するCPU
- **Normal** — 盤面・アーツ・エール要求に基づいて行動するCPU
- **Easy** — 合法手からランダムに行動するCPU

全難易度で相手の実際の手札や山札順は参照しません。探索はWeb Workerで行います。

CPU対戦は操作が確定するたびにブラウザーへ自動保存されます。「中断して設定へ戻る」やページを閉じた後、設定画面の「続きから再開」で復帰できます。保存は1件で、新しい対戦を始めるときは上書きを確認します。

保存先は同じブラウザー・同じURL内です。別の端末やURLには引き継がれません。使用カードやルール処理が変わり、安全に復元できない場合は再開を止めます。

## ローカルの2人対戦・観戦

`npm run dev` または `npm run serve` を起動し、別々のブラウザープロファイルから同じ部屋コードへ接続します。例:

```text
http://localhost:5173/?room=test
```

最初の参加者がプレイヤー1、次の参加者がプレイヤー2です。それぞれ名前とデッキを選び、2人そろうと対戦を開始します。サーバーが各操作のルールと権限を検証し、相手の手札などの非公開情報を伏せて配信します。観戦も可能です。

一時切断後60秒は席を予約し、同じブラウザープロファイルから再接続すると復帰できます。既定では1部屋16接続までです。

## プロジェクト構成

```text
src/                ゲーム処理・CPU・画面・スタイル・ロゴと背景
server/             ローカル対戦リレー・ビルド済みアプリの配信
tools/extraction/   公式カード・画像・おすすめデッキの取得
data/               取得したカードデータと画像（Git管理外）
```
